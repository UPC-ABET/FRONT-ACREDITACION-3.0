# ABET Frontend — Agent Instructions

Read both files below before doing any work in this repo, and follow them exactly:

- [`docs/POLICIES.md`](./docs/POLICIES.md) — mandatory rules ("you MUST"). Everything a
  reviewer would block a PR on.
- [`docs/CONTEXT.md`](./docs/CONTEXT.md) — orientation. Stack, structure, domain
  vocabulary, integrations, environment.

For spec-driven changes, see [`openspec/README.md`](./openspec/README.md). For
architecture decisions, see [`docs/adr/README.md`](./docs/adr/README.md).

If a convention needs to change, update `docs/POLICIES.md` or `docs/CONTEXT.md` in the
same change — not this file.
